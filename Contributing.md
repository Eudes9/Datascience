## Contribuer

Merci de votre intérêt ! Voici quelques étapes simples pour contribuer :

1. Forkez ce dépôt.
2. Créez une branche pour votre modification.
3. Faites un `commit` de vos changements.
4. Poussez votre branche et créez une Pull Request.

N’hésitez pas à ouvrir une *Issue* si vous avez des questions !
